<h1 align=center>Bob-The-Robot</h1>

A 3D robot project built in C++ using OpenGL and GLUT, created as a final assignment in a Computer Graphics course.

<br> </br>
🎯 Project Overview

Bob-The-Robot is a fully-interactive 3D robot model composed of multiple hierarchical parts.
The project demonstrates key Computer Graphics concepts including transformations, lighting, camera control, and real-time interaction.

<br> </br>
🧰 Features

* Hierarchical 3D modeling of a robot (body, head, arms, legs, etc.) using OpenGL primitives.
* Robot movement controls - rotating limbs, moving joints, and animating different parts.
* Camera manipulation - changing the viewpoint, rotating the scene, zooming in/out.
* Dynamic lighting controls - enabling/disabling light sources, adjusting intensity, and experimenting with different lighting setups.
* GLUT-based interaction - keyboard callbacks for movement, lighting, and camera settings.

<br> </br>
💡 Educational Value

This project showcases essential topics taught in an introductory Computer Graphics course:
Modeling with transformations (translate, rotate, scale)
Scene hierarchy and matrix stack concepts
Light and material properties
Real-time rendering and interaction
<br> </br>
The project was developed as a final assignment in course 20562 - Computer Graphics, The Open University of Israel.
